# Video to Markdown 安装与使用指南

本文适用于 Video to Markdown 0.2.0。插件目前支持 Chrome 114 及以上版本，以及带有可访问字幕的 YouTube、哔哩哔哩视频。

## 下载安装包

1. 打开仓库的 GitHub Releases 页面。
2. 下载当前版本的 `video-to-markdown-extension-<版本号>-chrome.zip`。
3. 将 ZIP 解压到一个固定目录。安装后不要随意删除或移动该目录。

如果仓库暂未发布 Release，可以在项目根目录运行：

```bash
pnpm install
pnpm build
```

随后使用 `.output/chrome-mv3` 目录进行安装。

## 安装到 Chrome

1. 在地址栏打开 `chrome://extensions`。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后的插件目录，或者本地构建产生的 `.output/chrome-mv3`。
5. 将 Video to Markdown 固定到浏览器工具栏，便于在视频页面打开。

更新插件时，替换原目录内容后回到 `chrome://extensions`，点击插件卡片上的刷新按钮。已经打开的视频页面也需要刷新一次。

## 生成第一篇 Markdown

1. 打开一个带字幕的 YouTube 或哔哩哔哩视频。
2. 点击 Video to Markdown 图标，打开浏览器侧边栏。
3. 等待插件读取视频标题、作者和字幕信息。
4. 选择最终文档语言：中文或 English。
5. 选择处理模式：
   - **高保真**：清洗字幕、恢复段落并尽量保留视频原意。
   - **AI 精炼**：提取重点并生成结构化笔记。
6. 根据需要开启“保留时间戳”。
7. 点击“开始生成”，在实时预览中查看已经验证的内容。
8. 完成后可以阅读预览、查看 Markdown 源码、复制或下载 `.md` 文件。

字幕轨道会由插件自动选择。只有需要覆盖自动选择结果时，才需要打开高级设置。

## 配置自己的模型 API

以下情况需要配置模型：

| 场景 | 是否需要模型 |
| --- | --- |
| 字幕语言与输出语言相同的高保真 | 否 |
| 字幕语言与输出语言不同的高保真 | 是，用于翻译 |
| AI 精炼 | 是 |

点击“模型设置”，填写：

- API Key
- HTTPS Base URL
- 模型名称
- 上下文窗口大小
- 流式模式

插件支持 OpenAI 兼容的 `/chat/completions` 接口。保存时，Chrome 会提示授权访问该模型服务来源；插件不会申请与模型无关的任意网站权限。

可以先点击“保存并测试”验证模型。连接测试只发送最小测试消息，不发送视频字幕。

## 常见问题

### 提示需要刷新页面

如果视频页面是在安装或更新插件之前打开的，Content Script 尚未注入。点击“刷新并重新检测”，或手动刷新视频页面后重试。

### 明明有字幕，却提示没有字幕

- 确认视频播放器中可以开启字幕。
- 刷新视频页面并等待播放器加载完成。
- 尝试切换到视频的标准播放页面，避免在首页预览、短视频浮层或嵌入播放器中提取。
- 平台接口发生变化时，请在 GitHub Issues 中附上视频链接、浏览器版本和插件版本。

### 模型长时间没有返回

生成界面会显示当前阶段、等待时间、接收字符数和已验证正文。插件会对临时错误自动重试；单个分块失败时会保留已经成功的内容。

如果持续没有响应，请检查模型名称、余额、Base URL、网络代理以及服务商是否支持 OpenAI 兼容协议。也可以把流式模式改为“自动”，让插件在服务不支持 SSE 时安全降级。

### API Key 保存在哪里

API Key 仅保存在本机的 `chrome.storage.local`，并限制为扩展可信上下文访问。需要模型时，字幕会直接发送给用户选择的模型服务商，不经过本项目服务器。更多信息见 [PRIVACY.md](../PRIVACY.md)。

## 卸载与清理

在 `chrome://extensions` 中移除插件后，Chrome 会清理插件本地数据。也可以在卸载前进入模型设置，使用“删除配置”单独移除 API Key。
