# Video to Markdown 安装与使用指南

本文适用于 Video to Markdown 0.2.1 及后续开发版本。插件支持 Chrome 116 及以上版本，以及 YouTube、哔哩哔哩视频；开发分支可直接转录没有字幕轨的 B 站视频音频。

## 下载安装包

1. 打开仓库的 GitHub Releases 页面。
2. 下载当前版本的 `video-to-markdown-extension-<版本号>-chrome.zip`。
3. 将 ZIP 解压到一个固定目录。安装后不要随意删除或移动该目录。

如果仓库暂未发布 Release，可以在项目根目录运行：

```bash
pnpm install
pnpm build
```

随后使用 `.output/chrome-mv3` 目录进行安装。

## 安装到 Chrome

1. 在地址栏打开 `chrome://extensions`。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载未打包的扩展程序”。
4. 选择解压后的插件目录，或者本地构建产生的 `.output/chrome-mv3`。
5. 将 Video to Markdown 固定到浏览器工具栏，便于在视频页面打开。

更新插件时，替换原目录内容后回到 `chrome://extensions`，点击插件卡片上的刷新按钮。已经打开的视频页面也需要刷新一次。

## 生成第一篇 Markdown

1. 打开一个带字幕的 YouTube 或哔哩哔哩视频。
2. 点击 Video to Markdown 图标，打开浏览器侧边栏。
3. 等待插件读取视频标题、作者和字幕信息。
4. 选择最终文档语言：中文或 English。
5. 选择处理模式：
   - **高保真**：清洗字幕、恢复段落并尽量保留视频原意。
   - **AI 精炼**：提取重点并生成结构化笔记。
6. 根据需要开启“保留时间戳”。
7. 点击“开始生成”，在实时预览中查看已经验证的内容。
8. 完成后可以阅读预览、查看 Markdown 源码、复制或下载 `.md` 文件。

字幕轨道会由插件自动选择。只有需要覆盖自动选择结果时，才需要打开高级设置。

### B站转载视频没有字幕轨

推荐直接转录当前视频：

1. 在无字幕页面展开“配置语音转写服务”。
2. 填写支持 OpenAI 音频转写格式的接口、API Key 和模型名称；普通对话模型接口不能使用。
3. 选择音频语言和分段时长，点击“保存配置并开始转录”。
4. 插件会暂存原播放位置，以 1 倍速从头播放并捕获当前标签页音频；转录结束或手动停止后恢复原播放状态。
5. 页面会持续显示录制时长、当前分段和已经识别的文字。视频播放完毕后，音频转写会作为新的字幕来源进入生成设置。

转录耗时接近视频时长，并会把音频分段直接发送到用户填写的转写服务，可能产生服务商费用。插件不上传视频画面，也不经过项目服务器。

如果不希望发送音频，可展开“不发送音频的其他方式”，优先尝试发布者文稿：

1. 在无字幕页面点击“自动查找发布者文稿”。
2. 插件会检查当前视频简介、UP 主置顶评论和其中明确提供的 B 站文稿链接。
3. 找到完整且可访问的文本型文稿后，插件会直接进入生成设置。
4. 发布者文稿没有可靠时间轴，因此“保留时间戳”会自动关闭。

插件只接受当前 UP 主提供并由同一 UP 主发布的 B 站文稿，不会搜索或猜测其他视频。如果文稿属于充电专属、粉丝专属或其他受限内容，插件会提供原文稿链接；用户需要在 B 站正常取得访问权限后再重新查找。图片型文稿和过短摘要不会冒充完整转录。

如果没有找到发布者文稿，但原始 YouTube 视频提供了字幕：

1. 展开无字幕页面中的“不发送音频的其他方式”。
2. 找到“使用 YouTube 原视频字幕”。
3. 粘贴完整的 HTTPS YouTube 视频链接，例如 `https://www.youtube.com/watch?v=...`。
4. 点击“读取字幕”。检测成功后，插件会自动选择该原视频的合适字幕轨。
5. 核对“字幕来源”中显示的 YouTube 原视频标题，然后开始生成。

也可以在生成设置的“字幕来源”高级区域重新填写原视频链接。插件只读取用户明确填写的视频 ID；链接无效、视频不可访问或原视频同样没有字幕时会停止处理，不会猜测其他视频。

## 配置自己的模型 API

以下情况需要配置模型：

| 场景 | 是否需要模型 |
| --- | --- |
| 字幕语言与输出语言相同的高保真 | 否 |
| 字幕语言与输出语言不同的高保真 | 是，用于翻译 |
| AI 精炼 | 是 |

点击“模型设置”，填写：

- API Key
- HTTPS Base URL
- 模型名称
- 上下文窗口大小
- 流式模式

插件支持 OpenAI 兼容的 `/chat/completions` 接口。保存时，Chrome 会提示授权访问该模型服务来源；插件不会申请与模型无关的任意网站权限。

可以先点击“保存并测试”验证模型。连接测试只发送最小测试消息，不发送视频字幕。

## 常见问题

### 提示需要刷新页面

如果视频页面是在安装或更新插件之前打开的，Content Script 尚未注入。点击“刷新并重新检测”，或手动刷新视频页面后重试。

### 明明有字幕，却提示没有字幕

- 确认视频播放器中可以开启字幕。
- 刷新视频页面并等待播放器加载完成。
- 尝试切换到视频的标准播放页面，避免在首页预览、短视频浮层或嵌入播放器中提取。
- 如果是B站视频且字幕已经烧录在画面中，先点击“自动查找发布者文稿”；没有结果时再指定 YouTube 原视频。
- 如果提示发布者文稿受限，请在 B 站打开文稿并正常取得访问权限，然后回到视频页重新查找。
- 稳定版 0.2.1 不能直接识别画面硬字幕；开发分支可以转录当前 B 站标签页音频，但不会对画面硬字幕执行 OCR。
- 平台接口发生变化时，请在 GitHub Issues 中附上视频链接、浏览器版本和插件版本。

### 模型长时间没有返回

生成界面会显示当前阶段、等待时间、接收字符数和已验证正文。插件会对临时错误自动重试；单个分块失败时会保留已经成功的内容。

如果持续没有响应，请检查模型名称、余额、Base URL、网络代理以及服务商是否支持 OpenAI 兼容协议。也可以把流式模式改为“自动”，让插件在服务不支持 SSE 时安全降级。

### API Key 保存在哪里

文本模型和语音转写服务的 API Key 仅保存在本机的 `chrome.storage.local`，并限制为扩展可信上下文访问。需要模型时，字幕或音频分段会直接发送给用户选择的服务商，不经过本项目服务器。更多信息见 [PRIVACY.md](../PRIVACY.md)。

## 卸载与清理

在 `chrome://extensions` 中移除插件后，Chrome 会清理插件本地数据。也可以在卸载前进入模型设置，使用“删除配置”单独移除 API Key。
