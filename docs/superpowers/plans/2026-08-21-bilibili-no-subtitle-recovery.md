# B 站无字幕视频提取优化实施计划

## 一、问题与目标

当前插件优先读取 YouTube、哔哩哔哩提供的字幕轨。部分 B 站转载视频只有画面硬字幕，没有平台字幕轨，现有流程只能要求用户手动填写 YouTube 原视频链接。这会带来三个问题：

- 用户未必知道原视频地址；
- 发布者可能已经在简介、置顶评论或哔哩哔哩文稿中提供了完整文字；
- 自动猜测相似视频容易再次产生“提取到其他视频”的严重错误。

本阶段目标是在不猜测其他视频、不绕过平台访问控制的前提下，自动利用当前视频发布者明确提供的内容；如果仍无可用文本，再进入音频转写兜底。

## 二、总体恢复链路

按可信度从高到低执行：

1. 当前分 P 的哔哩哔哩字幕轨；
2. 发布者在视频简介或 UP 主置顶评论中明确提供的哔哩哔哩文稿；
3. 发布者明确标注的 YouTube 原视频字幕；
4. 当前 B 站视频音频的云端 ASR 转写；
5. 用户主动触发的标签页音频实时转写；
6. 手动填写原视频链接或实验性 OCR/本地 Whisper。

禁止自动搜索并选择标题相似的其他 B 站或 YouTube 视频。

## 三、阶段拆分

### P2A：自动发现发布者文稿（本轮实施）

#### 数据来源

- `/x/web-interface/view`：稿件 aid、简介、UP 主 mid；
- `/x/v2/reply`：UP 主置顶评论；
- `https://www.bilibili.com/opus/<id>`：文稿页面中的服务端初始数据。

#### 安全与正确性约束

- 只接受 `https://www.bilibili.com/opus/<数字 ID>`；
- 置顶评论必须由当前稿件 UP 主发布；
- 文稿作者 mid 必须与当前稿件 UP 主 mid 一致；
- 不访问置顶评论中的任意第三方网址；
- 遇到充电专属、粉丝专属或其他受限文稿时，明确提示用户在 B 站获取访问权限，不绕过限制；
- 文稿字符量必须与视频时长相匹配，过短摘要不能冒充完整转录。

#### 产品交互

- 无字幕页面主操作改为“自动查找发布者文稿”；
- 查找时显示当前步骤；
- 找到公开或用户有权访问的文稿后，直接进入生成设置；
- 文稿受限时显示原因和原文稿链接；
- 未找到时给出明确结果，并将手动 YouTube 链接收纳到“其他提取方式”。

#### 验收标准

- 能从 UP 主置顶评论发现文稿链接；
- 能解析文本型哔哩哔哩 Opus 文稿；
- 能识别受限文稿并停止，不产生空结果；
- 拒绝非 UP 主置顶内容、非 B 站 Opus 链接和作者不匹配的文稿；
- 长视频的短简介/摘要不会进入生成；
- 无时间轴文稿不展示或导出伪造时间戳。

### P2B：当前视频音频云端 ASR（下一阶段）

- 新增独立的转写模型配置，不复用文本模型 `/chat/completions` 配置；
- 支持用户自带 ASR API Key；
- 优先获取当前 `bvid + cid` 对应音频，严格校验当前分 P；
- 分片上传、断点重试、进度与预计耗时可见；
- 转写结果保留真实时间轴并进入现有高保真/AI 精炼处理链路；
- 明确展示音频将发送至哪个服务商，并在用户点击后才开始上传。

### P2C：标签页音频实时转写（后续兜底）

- 使用 `tabCapture` 与 offscreen document；
- 运行时请求权限，不在安装时扩大权限；
- 保持标签页声音正常播放；
- 页面切换、暂停、关闭和断网均可恢复或安全停止；
- 明确提示实时转写通常需要接近视频时长的等待。

### P2D：实验能力

- 硬字幕 OCR：适合画面字幕稳定的视频，但需处理双语、遮挡与镜头切换；
- 本地 Whisper/WebGPU：隐私更好，但模型体积、显存、长视频稳定性需要单独验证。

## 四、技术改造范围

- `BilibiliAdapter`：新增发布者文稿发现与加载能力；
- `SubtitleTrack`：标识来源类型、是否具备真实时间轴、采用何种完整性策略；
- 文稿解析器：解析 Opus 初始 JSON，提取文本段并识别访问限制；
- 完整性校验：字幕轨使用时间覆盖率，发布者文稿使用字符量与视频时长的匹配度；
- `NoSubtitleView`：新增自动发现的状态机与结果提示；
- `PrepareView`：无时间轴来源禁用时间戳选项；
- 测试：解析器单测、适配器集成测试、页面交互测试和扩展 E2E 回归。

## 五、不在本轮实施的内容

- 不下载或上传 B 站音频；
- 不申请 `tabCapture`、`offscreen` 权限；
- 不绕过 B 站充电、粉丝或登录访问限制；
- 不通过搜索引擎或相关推荐自动猜测原视频；
- 不从画面执行 OCR。
