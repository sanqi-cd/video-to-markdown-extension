# Video to Markdown 0.2.0 中文说明

![Video to Markdown 图标](./public/icon/128.png)

Video to Markdown 是一个本地优先的 Chrome Side Panel 插件，可将 YouTube、哔哩哔哩已有字幕整理为中文或英文 Markdown。

## 处理方式

- **高保真**：清洗字幕并恢复段落，尽量保留原始信息和顺序；字幕与输出语言相同时无需模型，跨语言时自动翻译。
- **AI 精炼**：提取核心观点、事实、人物、案例和结论，形成指定语言的结构化笔记。
- **增量预览**：每个通过校验的分块立即展示；模型支持 SSE 时可进一步逐步接收内容。
- **失败恢复**：自动重试临时错误，保留成功分块并允许局部重试。

## 快速开始

1. 在 Chrome 开发者模式加载 `.output/chrome-mv3`。
2. 打开一个带字幕的 YouTube 或 B站视频，然后打开插件侧边栏。
3. 如果提示页面脚本尚未加载，点击“刷新并重新检测”。
4. 选择最终输出语言、处理方式和时间戳，点击“开始生成”。字幕来源默认自动选择，可在高级设置中覆盖。
5. 需要翻译或 AI 精炼时，再按引导配置自己的模型 API。
6. 在生成过程中查看实时进度，完成后复制或下载 Markdown。

| 场景 | 模型要求 |
| --- | --- |
| 字幕语言与输出语言相同的高保真 | 不需要模型，字幕不离开本机 |
| 字幕语言与输出语言不同的高保真 | 需要模型完成翻译 |
| AI 精炼 | 需要模型完成结构化提炼 |

流式模式设为“自动”时，不支持 SSE 的服务会安全降级为普通请求和分块增量。任何未完成、未通过结构校验的模型输出都不会写入最终文档。

## 隐私边界

API Key 只保存在浏览器本地，并限制为扩展可信上下文访问。需要模型的任务会把字幕段落直接发送给用户选择的模型服务商，不经过本项目服务器；同语言高保真不会调用模型。删除模型配置即可移除本地保存的 API Key。

## 已知限制

- 只处理平台已有字幕，不包含视频下载、音频提取或语音识别。
- 只支持 Chrome 114+ 和 OpenAI 兼容 `/chat/completions` 服务。
- 关闭 Side Panel 会取消当前请求，不支持后台续跑或跨会话恢复。
- 暂不支持飞书、Notion、Obsidian 同步及批量视频处理。
